# Japanese Official Source Census — Black 2 / White 2

## Purpose

This census tracks surviving Japanese first-party/official material directly relevant to Pokémon Black 2 and White 2. The Japanese releases are the comparison baselines for regional research. The page-level inventory is in `../manifests/official-jp-sources.csv`.

## Pokémon.co.jp — Black 2 / White 2

Root: `https://www.pokemon.co.jp/ex/b2w2/`

Core surviving HTML branches currently registered:

- Story root plus `story01.html`–`story03.html`.
- Character root plus `character01.html`–`character14.html`.
- Pokémon root plus `pokemon01.html`–`pokemon08.html`.
- System root plus `system01.html`–`system10.html`, covering PWT, Funfest Mission, Join Avenue, Xtransceiver minigame, Medal System, Key System, Memory Link, habitat list and communication functions.
- Download software: `/ex/b2w2/dlsoft/`.
- Pokémon Dream Radar / AR Searcher: `https://www.pokemon.co.jp/ex/ar_searcher/`.
- Pokédex 3D Pro: `https://www.pokemon.co.jp/ex/zenkokuzukan_pro/`.
- Product: `/ex/b2w2/product/`.
- News index: `/ex/b2w2/news/`.

Core category/subpage tree is **Enumerated-core**. The news branch remains **Enumerating** because individual notices, campaign destinations, promotional movies and external service pages must be itemized separately.
